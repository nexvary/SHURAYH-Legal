# SHURAYH

SHURAYH is a modern legal practice assistant for lawyers, designed first for Arabic-speaking legal professionals with strong RTL support and an architecture ready for Egyptian legal content, cases, clients, sessions, document scanning/OCR, legal drafting, reminders and secure local data.

## Current foundation

- Android native app in Kotlin + Jetpack Compose
- Arabic-first RTL UI with English resources ready
- Material 3 design foundation
- Android 15 target compatibility
- Dashboard skeleton for cases, clients, sessions, legal library and document tools
- GitHub Actions CI for build and unit-test verification

## Package

`com.nexvary.shurayh`

## Build locally

Open the repository in Android Studio, use JDK 17, sync Gradle, then run the `app` configuration.

CLI with an installed Gradle 8.11.1+:

```bash
gradle :app:assembleDebug
```

## Roadmap

1. Core navigation and RTL quality gate
2. Clients, cases and sessions database
3. Egyptian legal library and fast search
4. Legal document workspace, OCR and multi-page scan
5. Drafting and summarization assistants
6. Alerts, calendar and session reminders
7. Evidence/document vault and exportable reports
8. Licensing and release hardening

> SHURAYH assists legal professionals; generated or summarized legal material must be reviewed by a qualified lawyer before use.
